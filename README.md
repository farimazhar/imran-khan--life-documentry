# Imran Khan — A Life in Chapters

A Vercel-ready documentary-style animated timeline.

## Features

- 16 animated scenes
- Automatic scene progression
- Previous / Next controls
- Pause button
- Responsive mobile design
- No images or videos required
- No API key required
- Ready for Vercel

## How to use

Create a GitHub repository and upload:

- index.html
- style.css
- script.js
- README.md

Then import the GitHub repository into Vercel and deploy.

## Important

This is a browser-based animated documentary experience,
not a pre-rendered MP4 video.

The timeline is presented as a neutral biography.
Verify historical and current information before publishing.
